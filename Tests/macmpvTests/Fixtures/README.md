`seek-colors.mp4` is a generated six-second H.264 video: two seconds each of solid
red, green, and blue, at 320 × 180 and 10 fps. It has no audio or external content.
The thumbnail tests use its known colors to verify seeking to different times.

`seek-colors-one-keyframe.mp4` has the same colors but a single keyframe at 0 s, so
a keyframe preview anywhere shows red while an exact preview shows the real color.
